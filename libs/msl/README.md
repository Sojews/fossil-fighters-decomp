# MSL (Metrowerks Standard Library)

The C standard library the game was linked with. The headers and sources here come from the [Spirit Tracks decomp](https://github.com/zeldaret/st) (`libs/c`, commit `048ffeaa`), which is CC0. Most are used unchanged. This game's MSL is a little older: its string and memory functions work on plain (signed) `char`, so `string.c`, `mem.c` and `mbstring.c` are adjusted for that, and the functions Spirit Tracks doesn't have (`strcat`, `strchr`, `wctomb`, `wcstombs`, `__memrchr`) are written here. `wstring.h` declares `mbstate_t` only for C++. `wprintf.c`'s formatter has no secure-mode argument here (it predates it), `decimal.sgn` is a plain `char`, and the conversion digits are handled as `char`. `printf.c` is `wprintf.c` turned back into its narrow version (as the two MSL files mirror each other), with the conversions that differ (`%s`, `%c`, `p`, long double flags) and the small wrappers written to match. Both are compiled as C99 (`tools/configure.py`). A few files need small changes to build with this compiler's stricter settings (an `#include <stdbool.h>`, pointer casts), and `abort_exit_arm_eabi.c` declares its statics in the order that gives the game's layout. The `ctype.h` functions take `int` (so negative `char`s fail their range check) and `wctype.h` has the wide ones.

The original MSL objects were built with exception tables (their entries are in `.exceptix` at `0x02088498`). These files are built without them for now, so those entries stay in the unsplit data.
